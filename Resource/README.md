# Resource Folder

## File yang Diperlukan

### alarm-sound.wav

Anda perlu menambahkan file suara alarm dalam format WAV ke folder ini dengan nama `alarm-sound.wav`.

**Spesifikasi file:**
- Format: WAV (Waveform Audio File Format)
- Nama file: `alarm-sound.wav` (huruf kecil semua)
- Lokasi: `Resource/alarm-sound.wav`

**Cara menambahkan:**
1. Siapkan file audio WAV untuk suara alarm
2. Copy file tersebut ke folder `Resource/`
3. Rename file menjadi `alarm-sound.wav`
4. File akan otomatis di-embed sebagai Resource saat build (sudah dikonfigurasi di .csproj)

**Sumber file WAV gratis:**
- [Freesound.org](https://freesound.org/)
- [Zapsplat.com](https://www.zapsplat.com/)
- [Soundbible.com](http://soundbible.com/)

**Catatan:**
- Pastikan file berformat WAV (bukan MP3 atau format lain)
- Ukuran file sebaiknya tidak terlalu besar (< 1MB)
- Durasi suara alarm sebaiknya 2-5 detik untuk loop yang smooth
